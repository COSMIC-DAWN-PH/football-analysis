## 分析

1. **few-shot 反例效果显著**：两个反例样本把"球员经过≠球"直接教给了模型，b01722/b01723 从双误判变成双正确。qwen3.7 达到 20/20 全对。
2. qwen3.6 仅剩 c00009：它坚持认为该目标"在活跃比赛区、被球员围绕、轨迹像球"——与用户"场边垃圾"的事实冲突，说明模型对"球员围绕"仍可能过度泛化（该例 3.7 判对了，两模型互补）。
3. **两模型共识 ball = 0 个**（v7）：对"全非球"的 20 项，双模型共识策略零假阳。
4. 无 null：两模型都对视频信息有充分信心。

## 结论

- v7 判据（球员围绕 + 唯一球 + few-shot 反例）下模型预标质量显著提升：qwen37 全对，qwen36 19/20
- 采用"两模型都判 ball 才标记为疑似球"的策略，本组零误报——适合做全场预标的排序信号
- 全场 demo4（2956 项）将以 v7 判据+few-shot 跑双模型，产出预标文件供人工按"疑似球优先"审核
